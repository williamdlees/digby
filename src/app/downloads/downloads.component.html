Downloads

For each study in an AIRR-seq dataset, download a script that fetches its files with curl: the annotated repertoires (from MADC), the genotypes and the haplotypes of every sample. All data are free under CC0. The repertoire server has a download limit: if it returns HTTP code 503, it will say when you can retry.
